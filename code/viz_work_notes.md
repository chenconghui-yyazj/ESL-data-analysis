## 三、口径冲突与待核实处理

### 做区间处理的数字
- **全球市场规模**：2025年各机构口径差异大（1.52-3.10 十亿美元），图上以散点+区间竖线呈现，不取单一值。
- **中国市场规模 2025/2026E**：豆丁网多份报告给出 42.3/45/48.7 亿（2025）与 50.2/54.4/62/100.2 亿（2026E），图上以 min-max 区间柱呈现。
- **欧洲收入占比**：GMI 32.0% vs Polaris 40.1% vs PW 39.42% vs Dataintelo 28.7%，并存展示。
- **出货量**：2024年 ePaperInsight 3.7亿台 vs 元太 3.4亿片；2025年 ePaperInsight 5.0亿台 vs 洛图 5.4亿片；2026H1 洛图 1.7亿片 vs 同花顺 2.7亿片——灰色菱形标注第二口径。

### 移入待核实（pending_note 列）的记录
- **2026年全球市场规模 50 亿美元**（MarketsandMarkets 经搜狐转述，confidence=uncertain），保留在 CSV 但标注待核实。
- **沃尔玛"数亿标签"传闻**：官方口径为美国2300店+墨西哥170万枚，判定传闻不属实，未入图。
- **永辉单店1.8万枚**：第三方豆丁网报告，confidence=uncertain，仅在产业链图下游框标注。
- **维界SaaS 70%+**：项目内部PPT自述，无公开财报，在 chart_07 明确标注"项目自述目标，非行业现状"。
- **中国ESL渗透率"早年<10%"**：与2024年近30%冲突，旧口径，移入待核实。
- **电子价签渗透率68.4%**：豆丁网内容农场数字，无权威出处，已弃用。
- **SOLUM 2.4亿美元收入/12.3%市占**：ReportMines estimate，非年报审计数。

### 单位统一规则
- 金额：十亿美元直接保留为 USD bn；亿美元除以10转 USD bn；人民币保留亿人民币原始列；欧元/瑞典克朗保留原始列（chart_06 不做汇率换算）。
- 数量：亿台/亿片保留 unit_label 区分，不强行合并。

## 四、chart_10 ROI 计算假设与结果

| 参数 | 取值 | 来源 |
|---|---|---|
| 单店标签数 | 13,000 枚 | 区间 8000-20000 取中位（典型商超 SKU 量级） |
| 2.13寸单价 | 63 元/枚 | 淘宝国内零售价（2026-10） |
| 4.2寸三色单价 | 128 元/枚 | 1688 国内批发价（2026-10） |
| 单店硬件投入(2.13寸) | 13000 × 63 = 81.9 万元 | 计算 |
| 单店硬件投入(4.2寸) | 13000 × 128 = 166.4 万元 | 计算 |
| 年人工+纸张基线成本 | 15 万元/店 | 行业估算（未取权威报告，标"估算"） |
| 人工换标节省比例 | 60%-80% | 行业转述 Deloitte 口径（未取原始报告） |
| 年节省金额 | 9-12 万元 | 15 × 60% / 15 × 80% |
| 回收期(2.13寸) | 81.9 / 12 = 6.8 年 ~ 81.9 / 9 = 9.1 年 | |
| 回收期(4.2寸) | 166.4 / 12 = 13.9 年 ~ 166.4 / 9 = 18.5 年 | |

> **注意**：回收期偏长主要因硬件按国内零售/批发价全额计入；实际项目通常有规模采购折扣、SaaS订阅分摊、以及避免缺货/价格错误的隐性收益（未计入）。本图仅作测算示意，非权威财务数据。
