### 5.4 技术要点与踩坑记录

| 要点 | 原因 |
|---|---|
| **必须带 `--no-pdf-header-footer`** | 去除浏览器默认页眉（日期）与页脚（`file:///` 路径），否则 PDF 每页顶部会出现日期、底部出现本地路径，作品集不可用 |
| **必须带独立 `--user-data-dir`** | 若用户本机已运行 Edge，复用默认 profile 会导致 headless 实例不生成 PDF；指定 `$env:TEMP\edge_pdf_profile` 隔离实例 |
| **`@media print { @page { size: A4; margin: 14mm } }`** | 在 HTML 内控制打印版式，避免 Edge 默认页边距裁切图表 |
| **libpng 警告可忽略** | Edge headless 输出的 `libpng warning: iCCP: known incorrect sRGB profile` 不影响 PDF 渲染 |

## 7. 复现指南

### 7.1 环境要求

| 依赖 | 版本 | 用途 |
|---|---|---|
| Python | 3.x | 运行脚本 |
| pandas | 3.0.6 | CSV 读写 |
| matplotlib | 3.11.2 | 图表生成 |
| Pillow | 任意（PIL） | PNG 校验、chart_12 拼接 |

### 7.2 复现步骤

```powershell
# 1. 进入项目目录
cd C:\Users\陈聪惠\Desktop\维界投影数据分析

# 2. 复现 10 张清洗后 CSV（读取 data/*.json，输出到 data/*.csv）
python code\make_datasets.py

# 3. 复现 12 张 PNG 图表（读取 data/*.csv，输出到 images/*.png）
python code\make_charts.py

# 4. 检查输出
ls data\*.csv
ls images\*.png
```

### 7.3 脚本说明

| 脚本 | 输入 | 输出 | 关键逻辑 |
|---|---|---|---|
| `code\make_datasets.py` | `data/esl_market_data.json`、`esl_competitor_industry.json`、`esl_policy_business.json` | 10 张 CSV 到 `data/` | 按 metric 字段过滤；金额单位统一（亿美元→/10→USD bn）；`confidence=uncertain` 记录写入 `pending_note` 列 |
| `code\make_charts.py` | 10 张 CSV | 12 张 PNG（300dpi，白底）到 `images/` | matplotlib Agg 后端；Microsoft YaHei 中文字体；`add_source()` 图底部统一来源标注；`save()` 后用 PIL 校验 PNG 可打开 |

### 7.4 数据可追溯性

- 每张 CSV 每行保留 `source_url` 列，可直接溯源到原始网页。
- 每个图表底部有"数据来源："小字标注，与 viz_work_notes.md 第 47–60 行一一对应。
- 报告正文中每个数字都可在三份调研文档的 Markdown 底稿中按可信度 `verified/estimate/uncertain` 分级查找。
