# 数据字典（字段说明）

> 说明 `data/` 各文件的字段含义与口径，便于复现与面试讲解。


## market_size_global.csv（全球ESL市场规模（多机构口径））

| 字段 | 含义 |
|---|---|
| `year` | 统计年份 |
| `value_usd_bn` | 市场规模（十亿美元） |
| `agency` | 研究机构（Global Market Insights / Grand View / Mordor 等） |
| `source_url` | 来源链接 |
| `pending_note` | 待核实/口径备注（不同机构口径差异大，报告并存引用） |

## shipment_trend.csv（全球电子价签出货量（原始口径））

| 字段 | 含义 |
|---|---|
| `year` | 年份（含 2026H1 半年口径） |
| `units` | 出货量数值 |
| `unit_label` | 单位（亿片/亿台，不同来源口径不同） |
| `agency` | 数据机构/出处（CINNO、ePaperInsight、洛图、元太等） |
| `source_url` | 来源链接 |
| `pending_note` | 口径备注 |

## regional_share.csv（区域市场占比（多机构））

| 字段 | 含义 |
|---|---|
| `region` | 区域（欧洲/北美/亚太） |
| `metric` | 口径（收入占比等） |
| `share_pct` | 占比(%) |
| `year` | 年份 |
| `agency` | 机构 |
| `source_url` | 来源 |
| `pending_note` | 备注 |

## china_market.csv（中国市场（规模+渗透率））

| 字段 | 含义 |
|---|---|
| `year` | 年份（含2026E预测） |
| `value_rmb_100m` | 中国ESL市场规模（亿元人民币） |
| `penetration_pct` | 商超渗透率(%) |
| `metric` | 指标类型 |
| `scope` | 范围（如一二线/三四线） |
| `source_url` | 来源 |
| `pending_note` | 待核实（estimate） |

## policy_timeline.csv（政策法规时间线）

| 字段 | 含义 |
|---|---|
| `year` | 年份 |
| `region` | 区域（中国/欧盟） |
| `policy_name` | 政策/法规名称 |
| `key_point` | 要点 |
| `source_url` | 来源 |
| `pending_note` | 备注 |

> 三个 JSON 调研文件（esl_market_data / esl_competitor_industry / esl_policy_business）结构为 `{meta, records}`：`meta` 含采集说明，`records` 为带 `source_url` 的记录数组。
